# Home

Lura World Docs is a documentation site that organizes setup instructions and customization guidance for VRChat world assets.

At the moment, the site mainly covers the following two worlds.

- [LuminousHotel Guide](./luminous-hotel/overview.md)
- [LuminousOasis Guide](./luminous-oasis/overview.md)

There is also a shared section prepared for worlds that will be added later.

- [Future World Guides](./future-worlds/overview.md)

## How to use this site

Elements from each original world document have been reorganized into a more readable order. For LuminousHotel, you can follow the flow from setup to initial configuration, upload, customization, and troubleshooting without losing the intent of the original material.

## Current structure

### LuminousHotel

- Overview
- Setup and Installation
- Initial Scene Setup
- Upload and Quest Support
- Troubleshooting

### LuminousOasis

- Overview
- Setup and Installation
- Initial Scene Setup
- Upload and Quest Support
- FAQ
- Gimmick Reference

### Future World Guides

- Shared template for future world additions
- Placeholders for setup and extra explanation pages
