## What this document covers

- Creating a VCC project
- Installing VRC Light Volumes and UnityPackages
- Initial setup for RoomOwner, sign plates, and mood objects
- Example placement for a video player and VizVid
- Uploading for PC and Quest
- Customizing the mood board, photos, and Visitors Information Board

## Important notes before you begin

- If you are using the Full Pack, import the Full Pack UnityPackage last.
- Open scenes by double-clicking them in the Project window instead of dragging and dropping.
- LuminousHotel ver1.10 and later assume that VRC Light Volumes is installed.
- If TextMeshPro Essentials is missing, text rendering will break.
